# Шкаф в паркинг — 3D-редактор

Интерактивная 3D-модель шкафа для парковочного места (2600 мм) с роллетой. Внутри:

- металлический стеллаж;
- подъёмный стол и верстак;
- велосипед Aspect Air Elite 29 (рама L);
- четыре колеса 235/60 R18;
- автобокс 1850×840×420;
- фигуры человека ростом 180 см.

В редакторе меняются размеры шкафа и стеллажа (от оси места), высоты полок, стола и верстака. Положение велосипеда и автобокса тоже меняется. Проверки сразу показывают, что не помещается.

## Запуск

Это одна статическая страница без сборки и без сервера. three.js r128 лежит в `vendor/three/`, интернет нужен только для шрифтов. Без интернета страница работает с системными шрифтами.

- **Локально:** открыть `index.html` в браузере. Можно и через сервер: `python3 -m http.server`, затем http://localhost:8000.
- **GitHub Pages:** Settings → Pages → Source: *Deploy from a branch*, ветка `main`, папка `/ (root)`. Страница будет на `https://<user>.github.io/parking/`.
- **Любой хостинг статики** (Netlify, Cloudflare Pages, nginx и т.п.): выложить содержимое репозитория как есть.

## Данные

- Изменения сохраняются в `localStorage` браузера.
- «Скачать файл» сохраняет конфигурацию в `shkaf.json`.
- «Открыть файл» загружает её обратно. Так можно переносить настройки между устройствами.

## Состав

| Путь | Что это |
|---|---|
| `index.html` | редактор целиком (HTML + CSS + JS) |
| `vendor/three/` | three.js r128: ядро, OrbitControls, CSS2DRenderer, RoomEnvironment (MIT, см. `LICENSE`) |
| `extras/blender_parking_cabinet.py` | ранний скрипт для Blender; устарел, геометрия не совпадает с редактором |
